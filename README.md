# Travel Buddy

Multi-screen React Native app dengan React Navigation.

## Features
- Bottom Tab Navigation (Home, Search, Favorites)
- Stack Navigator di Home tab (HomeScreen → DetailScreen)
- Route params untuk pass destination data
- FlatList dengan daftar destinasi wisata
- Responsive UI menggunakan StyleSheet
- Icon navigation menggunakan @expo/vector-icons

## Tech Stack
- React Native
- Expo
- React Navigation 6
- JavaScript
- StyleSheet
- @expo/vector-icons
